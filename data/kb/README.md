# Generated encyclopedia artifacts

Everything under `data/kb/<patch>/` is machine-generated by the invoker
generation pipeline and committed for archival. Each artifact records its
own provenance: generator model, transport, prompt version, request hash,
context packet hash, and per-sentence citation marks that resolve against
the pinned substrate (corpus revisions, game-file snapshots).

Do not hand-edit artifacts — regenerate them (`invoker generate-concept …`).
